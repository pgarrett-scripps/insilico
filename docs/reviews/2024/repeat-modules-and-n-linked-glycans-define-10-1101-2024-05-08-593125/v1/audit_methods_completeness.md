# Methods Completeness & Reagent Traceability Auditor

## Summary
This manuscript reports structural, immunological, and glycosylation studies of EtpA, an enterotoxigenic E. coli adhesin, using cryo-EM, mass spectrometry, cell-based assays, and mouse/human antibody isolation. Detected categories include antibodies/immunodetection, cell lines, model organisms (mice), human subjects, chemicals/reagents, plasmids/constructs, mass spectrometry, microscopy/cryo-EM, and computational modeling (AlphaFold2). The manuscript is substantially detailed but contains gaps in cross-cutting items (sample sizes for some assays, statistical test naming, software versions), several unverifiable protocol delegations, and incomplete data/code availability statements. Key missing items include explicit n values for some binding assays, full gating strategies for flow cytometry, mass-spec repository accession, cryo-EM map/model deposition status (stated as 'prior to publication' but not yet deposited), and verification of several 'as previously described' citations.
