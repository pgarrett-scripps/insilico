# Reproducibility Reviewer

## Summary
This structural and immunological study of EtpA is well-executed with strong cryo-EM data and comprehensive mass-spectrometry glycosylation mapping. Reproducibility is generally sound: cryo-EM maps and models will be deposited in standard databases, mass-spectrometry methods are detailed with custom analysis scripts provided on GitHub, and monoclonal antibody isolation is fully specified. The main reproducibility friction is that native EtpA purification from H10407 is described only briefly with low peptide recovery, making independent replication of the native glycosylation profile (Supplemental Figure 7) difficult without author contact. Polyclonal epitope mapping relies on negative-stain EM with visual feature identification, which is inherently subjective and not easily automated. Overall, the work meets the standard for a structural biology paper, though some peripheral analyses would benefit from more consolidated procedural documentation.

## Strengths
- Cryo-EM structures will be deposited in EMDB and PDB prior to publication with stated resolutions (3.3–4.0 Å), enabling independent validation of atomic models and epitope assignments.
- Site-specific glycosylation analysis is supported by detailed LC-MS/MS methods (Orbitrap Eclipse, gradient parameters, search space, FDR thresholds) and custom GlycoMSQuant analysis scripts deposited on GitHub with a resolvable URL.
- Monoclonal antibody isolation from single plasmablasts is fully specified with cell-sorting markers, RT-PCR primer sets, cloning strategy, and transfection conditions, allowing replication of the mAb generation pipeline.

## Weaknesses
- Native EtpA glycosylation (Supplemental Figure 7, the only direct evidence that recombinant glycosylation recapitulates the native state) rests on purification from H10407 described only as 'flagellin null mutant (jf3099) grown in 4 L LB media' with ammonium sulfate precipitation and gel filtration; no yields, purity assessment, or troubleshooting guidance is provided, and the authors note 'low peptide detection in MS', making independent replication of this critical validation step infeasible without author contact.
- Negative-stain electron microscopy polyclonal epitope mapping (Figure 5, EMPEM) identifies 5–6 and 3–4 unique epitopes on NTS and CTR domains respectively by visual inspection of 2D class averages with 'false-coloring applied for clarity'; the procedure for distinguishing genuine epitopes from noise or artifacts is not specified, no quantitative criteria for epitope assignment are given, and no raw micrographs or class averages are deposited, making the epitope count non-reproducible without access to the original image dataset.
- Cryo-EM data processing is described with software versions (CryoSparc v2, Topaz neural network, non-uniform refinement) and particle counts at each stage (Supplemental Table 3), but the focused 3D refinement masks around Fab epitopes are not deposited or parameterized, and the decision criteria for subset selection during 2D and 3D classification are not specified, limiting independent replication of the final reconstruction.
- AlphaFold2 model generation for full-length EtpA required manual fragmentation (~700 residue chunks with 100-residue overlaps) and assembly in Chimera; no script or protocol for this procedure is provided, and the 'top combined score' model selection from ~300 ROSETTA models lacks specification of the scoring function, making this critical step non-reproducible.
- Biolayer interferometry binding kinetics (Supplemental Figure 1A, 1G05 and 1C08 Fabs) are described with instrument (Octet Red 96), biosensor type (Ni-NTA), and assay steps, but no raw sensorgrams, reference subtraction details, or curve-fitting software version are provided, and the 'global fit' procedure is not detailed.
- Erythrocyte pull-down and ELISA assays (Figures 1C–F) lack specification of replicate structure (technical vs. biological), plate blocking conditions beyond '1% BSA', and the exact HRP substrate incubation time and stop conditions, creating ambiguity in protocol reproducibility.
- Confocal microscopy (line 587–605) specifies antibodies and stains but does not state microscope settings (pinhole diameter, laser power, gain, offset, frame averaging), image processing (deconvolution, background subtraction), or quantification thresholds for adhesion quantification.
- Somatic hypermutation analysis uses ARMADiLLO (reference 70) but does not specify the tool version, input parameters, or confidence thresholds for mutation probability scoring shown in Supplemental Figure 8.

## Questions
- Will the raw cryo-EM micrographs and 2D/3D class averages be deposited alongside the final maps and models, or are they available only from the authors?
- For the native EtpA glycosylation profile (Supplemental Figure 7), can the authors provide the purification yield, SDS-PAGE purity assessment, and MS peptide count statistics to enable independent troubleshooting of the low-recovery protocol?
- What are the quantitative criteria (e.g., cross-correlation threshold, particle count per epitope class) used to assign distinct epitopes in the EMPEM analysis, and will the raw negative-stain micrographs be deposited?
- Can the authors provide the ROSETTA scoring function definition and the script used to assemble AlphaFold2 fragments in Chimera, or deposit a consolidated protocol on protocols.io?
