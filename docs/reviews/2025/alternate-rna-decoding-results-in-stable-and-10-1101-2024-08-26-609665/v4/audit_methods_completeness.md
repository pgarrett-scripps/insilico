# Methods Completeness & Reagent Traceability Auditor

## Summary
This manuscript reports a large-scale proteomics and transcriptomics study identifying amino acid substitutions in proteins from 1,094 human samples and 3 mouse tissues. Detected categories include Genomics/sequencing (RNA-seq), Mass spectrometry (proteomics), and Computational/ML (custom analysis pipelines). The work is substantially complete in specifying sequencing platforms, MS instruments, software versions, and analysis parameters. Data and code availability are stated. However, several protocol-provenance items are delegated to citations without full verification of their contents, and some quantitative details (e.g., exact FDR thresholds for specific analyses, replication structure for label-free data) require clarification.

## Categories checked
- Genomics/sequencing/omics
- Mass spectrometry (proteomics)
- Computational/ML/modeling
- Protocol provenance

**HARD gaps (blocking): 1** · SOFT gaps: 1 · unverifiable: 10

## HARD gaps — reproduction blockers
- **[Genomics/sequencing/omics] Library-prep kit identity** — No library-prep kit vendor or catalog number is specified. Only read source (Illumina paired-end) and minimum depth are given.

## Unverifiable (raise as questions)
- **[Genomics/sequencing/omics] Data repository accession (GEO/SRA/ENA)** — Manuscript states 'RNA-sequencing data was downloaded from NIH Genomic Data Commons (CPTAC data, portal.gdc.cancer.gov) or from dataset repository (label-free data, E-MTAB-2836)' — E-MTAB-2836 is an ENA accession, but CPTAC data source is not given a single accession number. Cannot verify from manuscript alone whether all raw RNA-seq files are deposited under a single resolvable accession.
- **[Mass spectrometry (proteomics)] Sample prep, digestion, enrichment protocol** — Methods state 'LC-MS proteomics data was downloaded' but do not describe sample preparation, protein extraction, or digestion in detail. Manuscript delegates to 'original publications' for CPTAC datasets (refs 20–25) and to dataset repositories for label-free data. Cannot verify from manuscript alone that full protocols are resolvable in those citations.
- **[Mass spectrometry (proteomics)] Repository accession (PRIDE/MassIVE)** — Manuscript states 'Supporting information, data, and documentation is available at decode.slavovlab.net' and 'The code is freely available at github.com/SlavovLab/decode' but does not provide a PRIDE or MassIVE accession number for the raw MS data. Cannot verify from manuscript alone whether raw proteomics files are deposited in a public repository.
- **[Mass spectrometry (proteomics)] Replication structure (technical/biological replicates per sample)** — Manuscript does not explicitly state whether each sample was run in technical replicates or whether replicates were averaged. For CPTAC TMT data, multiplexing implies one run per sample per experiment, but the number of independent digests or LC-MS runs per sample is not stated. For label-free data, replication structure is not specified.
- **[Computational/ML/modeling] Hyperparameters** — For XGboost model: no hyperparameters (learning rate, max depth, n_estimators, etc.) are stated. Manuscript says 'XGboost, R implementation version 1.7.7.1, was chosen for the classifier because it allowed for easily incorporating missing data features' but does not specify tuning or default parameters used.
- **[Computational/ML/modeling] Training procedure (optimizer, schedule, early-stopping)** — No training procedure details (optimizer, learning schedule, early-stopping criteria, convergence criteria) are provided for the XGboost model or any other custom ML component.
- **[Computational/ML/modeling] Random seeds or seed-averaging statement** — Manuscript states 'The model was retrained 1000 times on random subsets of test and train data' and 'The model was then retrained 100 times in the same manner leaving out one factor each time' but does not specify whether random seeds were set or reported for reproducibility.
- **[Protocol provenance] Protein degradation rate calculation (SILAC pulse-chase) — protocol resolvability** — Manuscript states 'Degradation rates (α) were computed using linear regression as the slope of ln(1+h/l)=αt, where h/l is the ratio between the heavy (h) and light (l) peptides abundance across time' — formula given, but the original SILAC pulse-chase protocol is delegated to 'ref. 39' (Mathieson et al. 2018, Nat Commun). Cannot verify from manuscript alone whether ref 39 contains sufficient detail to reproduce the experiment.
- **[Protocol provenance] gnomAD allele frequency and constraint analysis — protocol resolvability** — Manuscript describes the analysis ('Allele frequencies in gnomAD v4.1.0 (730,947 exomes) were calculated...') and cites gnomAD (ref 49, Chen et al. 2024, Nature). However, the exact filtering criteria, query method, and reproducibility of the gnomAD subset used are not fully specified. Cannot verify from manuscript alone whether the analysis is fully reproducible.
- **[Protocol provenance] RNA modification overlap analysis (nanopore DRS data) — protocol resolvability** — Manuscript states 'Using data by McCormick et al [38]' and describes the analysis ('We mapped all modified U sites from 6 cell lines to the coding sequences...') but does not provide the accession or full citation details for the nanopore dataset. Reference 38 (McCormick et al., bioRxiv, May 2024) is a preprint; cannot verify from manuscript alone whether the data are deposited or accessible.
