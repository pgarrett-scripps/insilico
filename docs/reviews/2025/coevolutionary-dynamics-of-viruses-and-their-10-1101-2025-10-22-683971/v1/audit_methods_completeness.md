# Methods Completeness & Reagent Traceability Auditor

## Summary
This is a theoretical computational modeling paper studying virus–defective interfering particle (DIP) coevolution using coupled partial differential equations. The triggered categories are Computational/ML/modeling. The manuscript provides the mathematical framework, non-dimensionalization, baseline parameters, and numerical solution domain, and states that code is publicly available on GitHub. However, several HARD items required for reproducibility are missing or unverifiable: random seed specification (stated as not applicable but not justified), exact software/library versions for the PDE solver, hardware specifications, and verification that the cited GitHub repository actually contains the complete, runnable code. Additionally, the initial condition distributions are described qualitatively but lack precise mathematical specification. The sensitivity analysis uses Latin Hypercube Sampling but does not report the random seed or sampling method version. These gaps prevent independent verification of the numerical results.

## HARD gaps — reproduction blockers
- **[Computational/ML/modeling] Library versions and hardware** — The manuscript states 'All code is publicly available at https://github.com/shivmuthupandiyan/virus-dip-coevolution' (lines 203–204) but does not specify: (1) the PDE solver library or version (e.g., FEniCS, MATLAB, Python scipy.integrate), (2) programming language version, (3) dependent library versions (NumPy, SciPy, etc.), or (4) hardware (CPU/GPU, memory, processor type) used for simulations. The sensitivity analysis (n=10,000 samples) likely required significant compute but no budget or hardware details are given.
- **[Computational/ML/modeling] Numerical solver details and convergence criteria** — The manuscript states the system is 'solved numerically on a [-5, 5] × [-5, 5] domain with zero-flux boundary conditions' (lines 207–200) but does not specify: (1) the PDE solver method (finite difference, finite element, spectral, etc.), (2) spatial and temporal discretization (grid spacing, time step), (3) convergence criteria or tolerance, or (4) how extinction thresholds (10^2) are enforced numerically. These are essential for reproducibility.

## Unverifiable (raise as questions)
- **[Computational/ML/modeling] Random seeds (or seed-averaging statement)** — The manuscript states 'We assume that in large populations, the stochastic effects are less prominent' (line 426) and uses a deterministic framework. However, the Latin Hypercube Sampling (LHS) sensitivity analysis (line 290) is inherently stochastic. No random seed is reported for the LHS sampling, and no statement is made about whether results are seed-averaged or from a single run. This is critical for reproducibility of the sensitivity analysis in Fig. 5.
- **[Computational/ML/modeling] Code availability** — Code availability is claimed: 'All code is publicly available at https://github.com/shivmuthupandiyan/virus-dip-coevolution' (lines 203–204). However, the manuscript does not verify that this repository is accessible, contains the complete code, includes all dependencies, or is documented sufficiently for independent execution. The auditor cannot confirm the repository contents from the manuscript alone.
- **[Computational/ML/modeling] Latin Hypercube Sampling (LHS) method and parameters** — The sensitivity analysis uses 'Latin Hypercube Sampling (LHS) (n = 10,000)' (line 290) but does not specify: (1) the LHS library or implementation, (2) the random seed, (3) whether the sampling was stratified or maximin-optimized, or (4) how the 10,000 samples were distributed across the six parameter dimensions. The parameter ranges are given (lines 293–295) but the sampling strategy is not fully specified.

## SOFT gaps — recommended
- **[Computational/ML/modeling] Compute budget / computational cost** — No information on wall-clock time, CPU hours, or GPU usage is provided. The sensitivity analysis involves 10,000 LHS samples (line 290), each requiring a full PDE simulation to steady state or classification, but no estimate of total compute time or resources is given.
- **[Computational/ML/modeling] Environment file / reproducibility package** — No environment file (e.g., requirements.txt, environment.yml, Dockerfile, or conda spec) is mentioned. The manuscript does not specify how to install dependencies or configure the computational environment.

## Documented (for the record)
- **[Computational/ML/modeling] Dataset(s) with version and exact train/val/test split** — The model is deterministic and does not use external datasets. Initial conditions are prescribed: 'initialized with a virus population of 10^6 and a DIP population of either 0 or 10^6. The initial virus and (when present) DIP populations were distributed as Gaussians (standard deviation = 0.4) centered at (1, 1) and (1.4, 0), respectively' (lines 212–214). The domain is '[-5, 5] × [-5, 5]' (line 207).
- **[Computational/ML/modeling] Architecture/algorithm specification** — The model is specified as a system of coupled partial differential equations (PDEs): Eqs (12) and (13) in the main text. The mathematical framework is fully described in the Methods section (lines 82–201), including the Gaussian interference kernel (Eq. 3), logistic regulation (Eq. 6), and fitness landscape terms.
- **[Computational/ML/modeling] Hyperparameters** — Baseline parameters are provided in Table 1 and Table 2, with dimensional and non-dimensional versions. Specific values: 'µ = 10^−3, η = 10^−3, α = 0.025, β = 0.025, κ = 10^−7, γ = 0.3. The carrying capacity, K, was set to 10^8' (lines 210–211). Sensitivity analysis sweeps are defined in lines 293–295.
- **[Computational/ML/modeling] Training procedure (optimizer/schedule/early-stopping)** — Not applicable; this is a deterministic PDE system solved numerically, not a machine-learning model. The system evolves from initial conditions to steady state or oscillatory dynamics. No optimization or training loop is employed.
- **[Computational/ML/modeling] Metric definitions** — Key metrics are defined: (1) population extinction threshold: 'A population was considered extinct when its total size fell below 10^2' (line 215); (2) chase classification: 'Dynamics were classified as 'Chase' when the variation in Euclidean distance between DIP and virus distribution centroids exceeded 0.1, and as 'Coexistence' otherwise' (lines 301–302); (3) resistance measured as 'fold reductions in interference' (line 341).
- **[Computational/ML/modeling] Ablation studies** — Ablations are present: (1) baseline dynamics without interference (κ=0, Fig. 2); (2) robustness tests with alternative interference kernels (Fig. S5: Gaussian, exponential, rational, step function); (3) higher-dimensional modeling (Fig. S4: 3D vs. 2D); (4) alternative distance metrics (Fig. S3: Earth Mover's Distance vs. Euclidean distance).
