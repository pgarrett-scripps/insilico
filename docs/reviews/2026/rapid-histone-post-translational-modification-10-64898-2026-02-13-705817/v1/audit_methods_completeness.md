# Methods Completeness & Reagent Traceability Auditor

## Summary
This proteomics manuscript describes a multi-protease histone PTM analysis workflow (RIPUP) using mass spectrometry. Detected categories: cell lines, model organisms, chemicals/drugs, mass spectrometry, and computational analysis. The manuscript provides extensive methodological detail for most MS parameters, histone extraction, and protease digestion conditions. However, several HARD gaps exist: (1) HEK293T cell line authentication and mycoplasma testing are not documented; (2) rat strain/source details are incomplete; (3) nicotinamide dosing vehicle and final concentration are not stated; (4) key MS search parameters (precursor/fragment mass tolerances, variable modification list) are delegated to supplementary tables not fully inspected; (5) statistical test specifications for limma analysis lack key details (e.g., dispersion estimation method); (6) random seed specification for k-NN imputation is absent. Data and code availability are properly declared. Most protocol references are resolvable, though some computational details remain in supplementary materials.

## HARD gaps — reproduction blockers
- **[Cell lines] HEK293T source, RRID, and authentication (STR)** — HEK293T cells are used throughout (nicotinamide treatment, histone extraction) but no source vendor, RRID, STR authentication, or mycoplasma testing is documented. Methods state 'HEK293T cells were cultured in Dulbecco's Modified Eagle Medium' but provide no cell line provenance or validation.
- **[Model organisms] Randomization and blinding statement** — No statement regarding randomization of animal assignment to groups or blinding of outcome assessment is provided. The manuscript does not indicate whether sample preparation or analysis was blinded.
- **[Chemicals/drugs/dosing] Nicotinamide (NAM) identity, vendor, catalog #, dose, vehicle, and final concentration** — NAM is identified as 'pan-sirtuin inhibitor nicotinamide (NAM)' with 'Millipore Sigma, catalog number N0636' and doses '3 mM or 10 mM'. However, the vehicle (e.g., DMSO, water, ethanol) and final concentration in culture media are NOT stated. The text says 'complete media supplemented with 3 mM or 10 mM NAM' but does not specify whether this is the final concentration or if dilution occurred.
- **[Computational/ML] Statistical test specification (limma)** — The manuscript states 'Differential abundance was assessed using the 'limma' package with empirical Bayes moderated t-statistics. A cell-means model was fitted with NAM dose (0, 3, 10 mM) as a factor, and contrasts were tested for 3 mM vs 0 mM and 10 mM vs. 0 mM.' However, critical limma parameters are not specified: (1) dispersion estimation method (e.g., 'robust=TRUE', 'trend=TRUE'); (2) whether voom or other variance-stabilization was applied; (3) the exact contrast specification syntax. These are necessary for exact reproducibility.
- **[Computational/ML] k-NN imputation random seed** — 'missing values were imputed using k-nearest neighbors (kNN, k = 10; Bioconductor 'impute' package)' is specified with k=10, but no random seed is stated. The 'impute' package's kNN function uses random sampling; without a seed, results are not reproducible.

## Unverifiable (raise as questions)
- **[Mass spectrometry] Precursor and fragment mass tolerances** — Methods state 'precursor mass tolerance was set to 10 ppm' for manual validation (Figure 6) and 'fragment mass tolerance was within 20 ppm' for the same figure. However, the automated search tolerances used in FragPipe are not explicitly stated in the main text; the manuscript refers to 'SI Table S1' for 'detailed mass offsets' but this supplementary table is not provided in the manuscript for verification.
- **[Mass spectrometry] Variable modifications and mass offsets** — The manuscript states 'Lists of variable modifications and detailed mass offsets are provided in SI Table S1' and 'For TMT-labeled samples, the monoisotopic mass of the intact label (+ 229.162932 Da) was set as a static modification on peptide N-termini and as a variable modification on K, and all other PTM declarations were consistent with unlabeled samples.' However, the complete list of variable modifications is delegated to supplementary materials not fully inspectable from the main text alone.
- **[Protocol provenance] Histone extraction protocol** — Methods state 'Cells were washed twice with DPBS before proceeding to nuclei isolation and histone extraction as described in SI Methods (Histone Extraction).' This delegates the core histone extraction to supplementary methods not provided in the main manuscript for inspection. The supporting information section lists 'Supplementary methods (histone extraction, SDS-PAGE, FragPipe search settings)' but the full text is not included in the provided manuscript.
- **[Protocol provenance] FragPipe HiP-Frag workflow parameters** — Methods state 'MS raw files were processed in FragPipe (v24.0) following the recommended guidelines for the HiP-Frag workflow, with some modifications' but the specific modifications are not detailed in the main text. Reference 20 (Vai et al. 2025) is cited, but the exact parameter deviations from that workflow are not enumerated, making independent reproduction difficult.
- **[Protocol provenance] Motif analysis for missed cleavage** — 'We performed motif analysis to determine whether any specific flanking residues contributed to missed R cleavage (SI Figure S6 and S7)' is mentioned, but the method (tool, algorithm, parameters) is not described in the main text. The supplementary figures are referenced but the computational approach is not detailed.
