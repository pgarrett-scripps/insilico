# Reproducibility Reviewer

## Summary
This is a well-executed, clearly written methods comparison with a genuinely interesting finding (TMT's tertiary amine rescuing ionization of acidic acylations) and a practical workflow contribution (RIPUP). The reproducibility gaps are concentrated in three places: the analysis code is not versioned, the HiP-Frag search configuration is not fully recoverable ("with some modifications"), and the headline TMT-vs-propionylation comparison crosses enzyme conditions without stating whether the search space is held constant. The data-deposition accession (PXD073683) and GitHub URL are stated but I could not verify either resolves. None of these are fatal to the science, but all three must be closed before an independent group could reproduce the load-bearing results.

## Weaknesses
- The TMT-rescues-acidic-acylation claim rests on a comparison that does not isolate the labeling chemistry. The evidence for the "dark epigenome" finding is the detection of 58 succinylation and 31 glutarylation sites in TMT-labeled samples versus few in propionylated ones (Figure 5B). But the comparison crosses enzyme conditions (Arg-C Ultra + TMT vs. Trypsin + Prop), and the manuscript never states whether the detailed mass offset list (SI Table S1) is identical across conditions. The alternative explanation — that the differential detection reflects a different search space or different peptide populations, not the TMT tertiary amine's charge compensation — is not excluded. What would settle it: a matched split-digest experiment (one Arg-C Ultra digest, half labeled with TMT, half with propionic anhydride, searched with identical parameters), reporting succinylation/glutarylation counts per condition. The mechanistic claim (charge compensation) is an inference from a confounded comparison and should be scaled to match.
- The "Arg-C Ultra outperforms Trypsin" headline comparison has an ambiguous basis. The manuscript acknowledges that the R-only Trypsin search overestimates labeling efficiency and that incomplete propionylation causes K cleavage (yielding ~2.2× more peptides in a KR search), yet the "substantially higher peptide identifications" claim in Figure 2C does not state which search underlies the comparison. If the R-only search is the basis, the comparison is biased against Trypsin; if the KR search, the peptide counts change materially. State explicitly which cleavage-specificity search produced the numbers in Figure 2C and the "217 vs 179" comparison.
- The analysis code is not versioned, and the search configuration is not fully recoverable. The custom R scripts are at a bare GitHub URL with no commit/tag or archived DOI — for load-bearing quantitative results (Figure 7's 112 significant peptidoforms), this is a HARD reproducibility gap. Separately, the FragPipe/HiP-Frag search is described as "following the recommended guidelines for the HiP-Frag workflow, with some modifications" — the modifications are never enumerated, so an independent group cannot reconstruct the exact search configuration. Provide a commit hash or archived DOI, and list the specific deviations from the published HiP-Frag workflow.
- No environment capture (lockfile, conda env, or container) or compute/hardware note for the FragPipe/R analysis — SOFT.
- No random-seed statement for kNN imputation (k=10), which is stochastic — SOFT.
- Scripts are not named per figure; the results-to-artifact mapping for Figures 2, 4, 5, and 7 is not explicit — HARD.
