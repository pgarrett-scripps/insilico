# Reproducibility Reviewer

## Summary
This is a substantial spatial-proteomics study with a clear two-part design (human post-mortem fractionation + TMT, mouse QUAD degradation across three ages) and a plausible cross-species integration. The reproducibility infrastructure, however, is incomplete in ways that currently prevent an independent group from rerunning the analysis end-to-end: no data availability statement or accession numbers for raw MS data, no code availability, and several key analysis parameters (ANOVA settings, human–mouse correlation thresholds, Day0 pooling sizes) left unspecified. The processed data in supplementary tables partially mitigates this, but the load-bearing claims cannot currently be reproduced from the described inputs.

## Strengths
- The fractionation protocol is described in sufficient detail (buffers, centrifugation speeds, detergent conditions) that an independent lab could replicate the wet-lab procedure.
- The QUAD design is clearly explained, including the Day0/Day7 chase logic and the pooling strategy for biological replicates.
- The "performed as previously described" references (refs 7, 17, 18) resolve to published sources containing the procedures, satisfying the cross-cutting requirement for method traceability.

## Weaknesses
- The claim that "78% of significant AD-associated alterations were restricted to a single fraction" (Figure 4C) cannot be reproduced from the described analysis. The ANOVA was "performed in ProteomeDiscoverer 2.5" with no statement of normalization method, multiple-testing correction (FDR? Benjamini–Hochberg?), or significance threshold. The 78% figure is the paper's central quantitative claim, and an independent group could obtain a very different percentage depending on these settings. Additionally, the raw MS data (raw files, peak lists, search results) are not deposited anywhere stated — no PRIDE/MassIVE accession, no data availability section at all. The supplementary tables contain processed protein-level data, but not the peptide-level or raw data needed to re-run the ANOVA. What would resolve it: state the ANOVA parameters (normalization, correction, threshold) and deposit raw MS data with a working accession.
- The QUAD degradation claims (Figure 8E–H, Figure 9) rest on an incompletely specified analysis pipeline. The Day0 pooling is described as "an equal number of male and female mice were pooled for each fraction," but the number of mice per pool is not stated — this matters because the Day7/Day0 ratio variance structure depends on how many animals contributed to the Day0 denominator. The TMT normalization procedure (e.g., total peptide amount normalization, reference channel scaling) is not described. The "median Day0 protein TMT value" division is stated, but not how missing values were handled in the ratio calculation. What would resolve it: state the number of mice per Day0 pool, the TMT normalization method, and the missing-value handling.
- The cross-dataset comparison yielding "155 protein measurements" and the "six proteins" at 2 months (Figure 9E) lacks specified criteria. The text says "Using these stipulations, we identified 155 protein measurements... that correlated" — but the correlation threshold, p-value threshold, and the exact definition of "altered" in the human data are not stated. Similarly, the six proteins at 2 months are presented as an "overlap" without the filtering criteria that produced them. What would resolve it: specify the exact thresholds and filtering steps for both the 155-measurement correlation and the six-protein overlap.
- No data availability statement or accession numbers for raw MS data anywhere in the manuscript — HARD for all load-bearing claims.
- No code availability for any custom analysis (e.g., the human–mouse correlation, the Tau correlation analysis, the WGCNA post-processing) — HARD.
- Software versions incomplete: MetaNetwork, Webgestalt, PACOM, and Cytoscape are named without versions — SOFT.
- Fractionation volume not specified: "H1 buffer with 0.5% NP-40 was added to the P1 pellet" — the volume is not given, which affects the extraction efficiency — SOFT.
- Results-to-artifact mapping is implicit: the manuscript does not state which data + which step produces each figure (e.g., which ProteomeDiscoverer export feeds which WGCNA input) — SOFT.

## Questions
- What were the exact ANOVA settings in ProteomeDiscoverer 2.5 (normalization, multiple-testing correction, significance threshold) for the human fraction analyses?
- How many mice were pooled into each Day0 sample for the QUAD analysis, and how was TMT data normalized before the Day7/Day0 ratio calculation?
- What specific thresholds defined the "155 protein measurements" correlation and the "six proteins" overlap between human and mouse datasets?
- Where will the raw MS data (raw files, peak lists, search results) be deposited, and under what accession?
