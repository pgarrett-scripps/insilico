# Reproducibility Reviewer

## Summary
This is a spatially resolved proteomics study with a clear and interesting design: four subcellular fractions from 27 human hippocampi, plus a QUAD degradation experiment in an AD mouse model across three ages. The protocols are mostly described in enough detail to repeat, and the "as previously described" references resolve to published sources. However, the manuscript is not currently reproducible end-to-end: there is no data availability statement or repository accession for either MS dataset, no normalization description for the TMT intensities that underlie every quantitative claim, and key analysis parameters (WGCNA, human–mouse matching) are unspecified. These are fixable, but they are load-bearing gaps, not friction.

## Strengths
- The fractionation, QUAD, and click-chemistry protocols are described with sufficient specificity (centrifugation speeds, buffers, chase times), and the "as previously described" citations resolve to published methods.
- Instrument, gradient, and search parameters are unusually complete: Uniprot database versions with dates, FDR, static modifications, and TMT lot-specific reporter correction factors are all stated.
- The supplementary table structure maps cleanly to the figures, giving a clear processed-data organization — assuming the files exist and are attached.

## Weaknesses
- No raw data deposition (HARD). The manuscript contains no Data Availability section and no repository accession (PRIDE, MassIVE, ProteomeXchange) for either the human or mouse MS datasets. Every quantitative claim in the paper — the 6,123 human proteins, all fraction-specific ANOVA results, all QUAD Day7/Day0 ratios — rests on data an independent group cannot obtain. This is the field standard for proteomics and is the single largest reproducibility gap. The fix is a repository accession, which should be stated in the manuscript.
- No normalization description for TMT reporter ion intensities (HARD). The methods state the statistical tests (ANOVA in ProteomeDiscoverer 2.5; t-tests on log2-transformed Day7/Day0 ratios) but never state how TMT reporter intensities were normalized across channels — total-intensity scaling, reference-channel scaling, median centering, or none. The reference channel is described as created ("Two microliters from all peptide samples were pooled and used reference channels") but its role in normalization is not stated. Normalization choices materially change AD/NA ratios and the fraction-specific comparisons that are the paper's central claim; a replicator cannot know whether the reported values would be reproduced.
- WGCNA parameters not specified (HARD for the module-based claims). "WGCNA was performed by MetaNetwork" with no soft-threshold power, minimum module size, merge cut height, or MetaNetwork version. The module eigenproteins (Figure 2E, 3A) and their enriched pathways are load-bearing for the vesicle-trafficking and protein-folding conclusions. WGCNA module structure is highly parameter-sensitive; the pathway enrichments depend on these choices.
- Human–mouse cross-dataset matching procedure not specified (HARD for the overlap claims). The 155 correlated measurements and the six early-stage proteins (Figure 9E) depend on how human and mouse proteins were matched (gene symbol? orthology? accession?) and on the exact inclusion thresholds (p < 0.05 in both datasets? fold-change cutoffs? the directionality criterion is described only in prose). A replicator cannot reproduce the overlap lists without this.
- Processed data not visible to me (HARD if the supplementary files are not attached to the preprint). The 18 supplementary tables are the processed outputs for every figure, including the human sample metadata (Table S1) used in the Braak correlation. I cannot verify their contents from the manuscript text, and no data availability statement confirms they exist anywhere. If they are attached to the preprint, this is resolved; if not, the processed data are as unavailable as the raw data.
- Day0 pool size and AHA incorporation not reported (SOFT). The QUAD ratio divides each Day7 measurement by a single pooled Day0 value per genotype per timepoint, but the number of mice in the Day0 pool is not stated, and no AHA incorporation efficiency is reported. The pool's representativeness is load-bearing for every degradation ratio.
- Human tissue access path not described (SOFT). The tissue source is named (Shiley-Marcos ADRC, UCSD) but no cohort identifiers, consent constraints, or application process are given. Controlled access is legitimate for human tissue, but the path must be described.
- Software versions incomplete (SOFT). MetaNetwork, PACOM, Cytoscape, and Prism versions are absent; the text cites both WebGestalt 2017 and 2024 without stating which was used.
- TMT set assignment not specified (SOFT). The 27 human samples were split into two 16-plex sets per fraction, but which samples went into which set is not stated, so a replicator cannot assess batch structure between sets. (Statistical validity of the batch handling is data_analysis's call.)
- Search tolerances omitted (SOFT). Precursor and fragment mass tolerances for the ProteomeDiscoverer searches are not stated.

## Questions
- What is the repository accession for the raw MS data (human and mouse), and will the supplementary tables be deposited alongside the preprint?
- What normalization was applied to the TMT reporter ion intensities before the ANOVA and before the Day7/Day0 ratio calculation?
- What were the WGCNA parameters (soft threshold, min module size, merge cut height) and the MetaNetwork version?
- How were human and mouse proteins matched for the cross-dataset overlap, and what were the exact inclusion thresholds for the 155 measurements and the six 2-month proteins?
- How many mice were pooled for the Day0 samples at each timepoint and genotype, and was AHA incorporation measured?
