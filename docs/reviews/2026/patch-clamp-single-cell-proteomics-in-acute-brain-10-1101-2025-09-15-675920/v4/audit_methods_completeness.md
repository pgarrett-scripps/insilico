## HARD gaps — reproduction blockers
- **[Cross-cutting (sample size, statistics, software versions, data/code availability, protocol provenance)] Biological vs. technical replicate distinction** — The electrophysiology section states n values for gigaseal-preserved neurons (n=3) and for the correlation analysis (n=6). However, the overall number of neurons collected (12) is stated indirectly; the total n for the shotgun dataset is given in figure legends and the results but not in a unified 'n per group' statement that distinguishes biological (individual neurons) vs. technical replicates. No explicit statement of what error bars represent (SD/SEM/CI) is found in figures or legends where error bars appear (e.g., Fig 3D-E shows regression lines without error bars on individual points; no bar chart with error bars is shown). A named statistical test is reported (e.g., F-tests for regression, Q-values for SynGO enrichment) but the text does not systematically specify which test was used for each comparison or whether assumptions were checked. Software versions: pClamp10 (no subversion), NeuroExpress (version 19.4.09), DIA-NN v1.8.1, R 4.3.1 are stated; Orbitrap Astral and Vanquish Neo UHPLC are named but no instrument firmware/software version. The authors state the raw MS data have been deposited to ProteomeXchange (PXD068359) and MassIVE (MSV000099156). Code availability: a GitHub link is provided (https://github.com/LarryThePharmacologist) but it is unclear whether the exact analysis scripts used for the paper are deposited; the repository appears to contain custom scripts for figure generation and SynGO analysis but the manuscript does not state whether a specific release/version or DOI is associated. 'Protocol provenance' triggers: many methods are delegated (e.g., 'as previously described [10,26-31]'). For the delegated methods (slice preparation, electrophysiology), the references [10,26-31] are given with full citations (authors, journal, year, volume, pages/DIO) and appear resolvable. However, no statement about deviations from those protocols is made. The key method of 'gigaseal preservation during retrieval' is described in the Methods, not delegated, so the core innovative step is self-contained.
- **[Cross-cutting (sample size, statistics, software versions, data/code availability, protocol provenance)] Error bar definition (SD/SEM/CI)** — No figure legend or results text states what error bars or ribbons represent (SD/SEM/CI). In Fig 3D-E, individual data points and regression lines are shown without error bars; no bar graphs with error bars are used.

Not all comparisons have a named test; the manuscript does not contain a statistics subsection.

IACUC protocol number: 'protocol no. 09-0006'. Number per group: the electrophysiology and proteomics used 12 neurons from an unspecified number of animals. No statement of randomization or blinding.
- **[Model organisms / in vivo] Genotype and background** — Animals are stated as 'Wistar rats (75 days of age, Charles River)'. No genotype or background strain details beyond 'Wistar' are provided. Wild-type status is implied but not stated.
- **[Model organisms / in vivo] Number of animals used (n per group)** — The methods describe 12 neurons collected, but do not state how many animals were used. Without this, the 'n per group' for the animal-level replication is unclear.
- **[Model organisms / in vivo] Randomization/blinding statement** — No statement about randomization of animals to conditions or blinding of electrophysiologists to group/treatment is present.
- **[Chemicals/drugs/dosing] Chemical vendor and catalog number (or CAS)** — The internal solution composition is given (145 mM KGluconate, 0.5 EGTA, 2 MgCl2, 10 HEPES, 2 Mg-ATP, 0.2 Na-GTP) but no vendor or catalog numbers for any of these chemicals are provided. aCSF composition is given with concentrations but no vendor/catalog numbers. n-Dodecyl-β-D-maltoside (DDM) is mentioned without vendor/catalog number. Trypsin (sequencing-grade, Promega) is named with vendor but no catalog number.
- **[Computational/ML/modeling] Random seed for stochastic analyses** — Custom SynGO analysis was performed. The manuscript states: 'Custom scripts for figure generation and SynGO-based analysis are available at https://github.com/LarryThePharmacologist'. The exact R packages and versions used (ComplexHeatmap, ggplot2, UpSetR) are listed. However, no random seed is stated for any analysis that involves randomness (e.g., PCA, clustering). No hardware details (CPU/GPU) are provided. No train/val/test split is applicable. The SynGO analysis uses a curated database; its version is not specified (SynGO version/date).
- **[Computational/ML/modeling] SynGO database version/release date** — SynGO version/date not specified. The reference cited (Koopmans et al., 2019) is a static publication, but the online database may have been updated since. The exact version of the annotation resource used is not stated.
