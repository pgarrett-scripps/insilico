# Reproducibility Reviewer

## Summary
The manuscript presents a novel single-cell top-down proteomics (SC-TDP) workflow for cardiomyocytes with interesting biological findings regarding proteoform heterogeneity. However, critical reproducibility barriers exist: raw mass spectrometry data are promised 'via figshare' without a working accession number or DOI, the ProSight PD 4.5 database conversion procedure is not detailed, key analysis parameters (e.g., how the 200 Da delta search was applied, exact filtering logic) lack procedural specificity, and the computational environment (software versions, hardware) is incompletely specified. While the bulk validation and single-cell workflow are reasonably well-described, an independent group would struggle to reproduce the proteoform identifications and heterogeneity claims without author contact.

## Strengths
- Raw MS data availability is stated as a commitment ('available via figshare'), indicating intent to share, though not yet deposited with a working accession.
- Bulk cardiomyocyte validation (10 ng, triplicate) is described with sufficient detail (gradient, flow rate, MS settings) to enable partial replication of that control.
- Key MS instrument settings are provided: Orbitrap Fusion Lumos, resolving power 15,000–60,000, AGC targets, RF lens 75%, EThcD + HCD fragmentation modes, isolation window 3 m/z, dynamic exclusion 6000 s.
- Nano-LC conditions are specified: C4 reversed-phase (2.7 µm, 1000 Å Halo), mobile phases, gradient profiles (60 min for cells, 35 min for standards), flow rate 300 nL/min.
- Single-cell isolation and lysis procedure is detailed: CellenONE X1 device, 384-well plate format, lysis buffer composition (30% TFE, 65% DMSO, 5% formic acid, protease/phosphatase inhibitors), sonication step.
- Data analysis workflow names key software (ProSight PD 4.5, Xtract, UniDec, TDValidator, ProSight Lite) and specifies search strategy: three-node approach with 200 Da (wide), 2.2 Da (narrow), and 10 ppm (truncation) tolerances, 1% FDR filtering.
- Reproducibility of chromatographic profiles across 13 cells is demonstrated (Figure 1), and technical replicate overlap is shown (Figure S4), supporting robustness claims.

## Weaknesses
- **HARD: Raw MS data accession missing.** The manuscript states 'Raw spectrum data are available via figshare' but provides no DOI, URL, or accession number. This is a load-bearing artifact for all proteoform identifications; without a working link, reproducibility cannot be verified. A preprint posted 28 March 2026 should have a deposited dataset with a resolvable identifier.
- **HARD: ProSight PD database conversion procedure not specified.** The text states 'The database was subsequently converted into a ProSight PD-compatible (.psdb) database' but does not describe how this conversion was performed, what parameters were used, or whether custom scripts were involved. This is a critical procedural gap for the search step.
- **HARD: 200 Da delta search application unclear.** The manuscript mentions 'Expanding the delta search to 200 Da revealed many previously unknown structural deviations' but does not specify: (i) which of the three search nodes applied this tolerance, (ii) whether it was applied to all cells or a subset, (iii) how results were filtered or prioritized, or (iv) the computational order of operations. This undermines reproducibility of the novel proteoform claims.
- **HARD: ProSight PD version and environment not fully specified.** While ProSight PD 4.5 is named, the Thermo Fisher Scientific software version, any patches, and the operating system/hardware on which searches were run are not stated. Deconvolution (Xtract) and UniDec versions are also not provided, affecting exact reproducibility.
- **HARD: Mus Musculus database version and annotation date not provided.** The text refers to 'a Mus Musculus database (Uniprot)' but does not specify the UniProt release date, whether canonical or isoform sequences were included, or how 'annotated modifications' were defined. This is critical for proteoform matching.
- **SOFT: FDR filtering logic not fully detailed.** The manuscript states '1% FDR threshold at both the protein and proteoform levels' but does not explain whether FDR was calculated per-node or across all three nodes, or how ties/borderline cases were handled. The ProSight PD documentation may clarify this, but it should be explicit here.
- **SOFT: Intermediate data and processing outputs not mentioned.** No statement is made about whether deconvoluted spectra, intermediate search results, or per-cell identification tables (beyond Table S2) are available. Reproducers would benefit from access to these to verify the pipeline.
- **SOFT: Random seed or stochastic parameter handling not addressed.** The manuscript does not state whether ProSight PD searches are deterministic or whether any stochastic steps (e.g., in Xtract deconvolution) require seed-setting for reproducibility.
- **SOFT: Supporting Information tables (S1, S2) referenced but not shown in the manuscript text.** While the tables are mentioned as available, their exact structure, column definitions, and how they map to the 57 proteins and 165 proteoforms are not described in the main text, making it harder to verify the results without accessing the supplementary files.

## Questions
- Where is the figshare accession or DOI for the raw MS data? Please provide a working, public link or accession number so that independent researchers can access the load-bearing dataset.
- How was the Mus Musculus UniProt database selected, dated, and formatted for ProSight PD? Which UniProt release was used, and were canonical sequences, isoforms, or both included?
- Can you provide the exact procedure for converting the UniProt database into a .psdb file? Were custom scripts used, and if so, are they available?
- In the three-node search strategy, which node(s) applied the 200 Da delta search tolerance? Was this applied to all 13 cells or only a subset, and how were results from this node prioritized or filtered?
- What versions of Xtract, UniDec, and ProSight Lite were used? On what operating system and hardware were the searches executed?
- How was the 1% FDR calculated: per-node or across all three nodes simultaneously? How were borderline identifications (near the FDR threshold) handled?
- Are the deconvoluted spectra, intermediate search results, or per-cell identification lists (beyond Table S2) available for inspection?
- Does ProSight PD 4.5 employ any stochastic steps in its search or deconvolution algorithms? If so, are results deterministic or do they require seed-setting?
- Can you clarify the structure and column definitions of Supporting Information Tables S1 and S2 in the main text, so readers can understand how the 57 proteins and 165 proteoforms are enumerated?
