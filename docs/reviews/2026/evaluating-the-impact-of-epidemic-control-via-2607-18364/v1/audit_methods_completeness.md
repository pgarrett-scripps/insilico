# Methods Completeness & Reagent Traceability Auditor

## Summary
This manuscript develops a theoretical stochastic epidemic framework with regime-switching and applies it to mpox data. Triggers detected: Computational/ML (mathematical model with numerical implementation), Chemicals/drugs (epidemiological parameters), and Protocol provenance (cited methods). The baseline SIR model was calibrated to publicly available mpox incidence data using maximum likelihood under a Poisson observation model. Numerical scenarios are evaluated conditionally on fitted parameters. Key computational details (software versions, random seeds, code availability) are partially documented. The empirical application is intentionally limited and uses specified rather than estimated intervention parameters. Data availability is stated as public; code availability is conditional on request.

The analysis used reported daily mpox case counts over the period from 16 June 2022 to 13 September 2022.'
- **[Computational/ML/modeling] Train/validation/test split specification** — Section 3.1: All 14 weekly aggregated counts from the complete observation window (16 June to 13 September 2022) were used for baseline calibration. No explicit train/test split is stated because the entire series is used for one-phase model fitting, and scenario comparisons are conditional on fitted parameters rather than evaluated on held-out data.
- **[Computational/ML/modeling] Algorithm and architecture specification** — Section 2: Theorem 2 and Corollary 3 specify the recursive algorithm for computing the joint Laplace–Stieltjes transform and probability generating function. Section 3.1 specifies the deterministic SIR calibration system with dS/dt, dI/dt, dR/dt equations and Poisson observation model.
- **[Computational/ML/modeling] Hyperparameters and key parameters** — Section 3.1: Recovery intensity γ = 1/3 per week (fixed); transmission coefficient b estimated; initial conditions S(0), I(0) estimated. Box constraints: b ∈ [0.05, 3.00], S(0) ∈ [55, 275], I(0) ∈ [10^−4, 10], κ ∈ [0.05, 20000]. ODE integration: fixed-step fourth-order Runge–Kutta with 100 substeps per week (step size 0.01 weeks). Abate–Whitt inversion: A = 18.4, 15 initial terms, 11 Euler averaging terms.
- **[Computational/ML/modeling] Training procedure (optimizer, schedule, early stopping)** — Section 3.1: 'The negative log-likelihood was minimized with the L-BFGS-B algorithm (Byrd et al., 1995).' Multiple starting values used: first Poisson starting value from initialization rule θ^(0)_P = (0.552, 66, 1); additional starting values generated randomly within bounds; for negative-binomial, θ^(0)_NB = (0.8, 66, 1), κ^(0) = 20, with κ sampled on logarithmic scale. No explicit early stopping criterion stated.
- **[Computational/ML/modeling] Metric definitions** — Section 2.3 and 2.4 define extinction time T, infection count N_I, total outbreak size C_I, and mixed moments μ^(k,r)_{s,i,p}. Section 3 reports means, standard deviations, variances, and correlations Corr(T, C_I) for each scenario.
- **[Computational/ML/modeling] Ablation studies or sensitivity analysis** — Section 3 presents four scenario groups isolating different intervention mechanisms: Scenario 1 (control intensity), Scenario 2 (intervention timing), Scenario 3 (vaccination effect), Scenario 4 (state-dependent escalation).
