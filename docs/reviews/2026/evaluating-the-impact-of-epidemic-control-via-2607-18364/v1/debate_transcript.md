## Skeptic — round 1

The advocate's strongest concession — that the disclaimers are honest — doesn't address the reviewers' more serious point: nobody can verify the numbers are right. The methodology reviewer flags, as HARD, that 'no positive control or validation of the recursive method against independent benchmarks' exists — no Monte Carlo cross-check, no comparison to matrix exponentiation, for a framework whose entire selling point is exact computation via Theorems 2–4. Compounding this, the reproducibility reviewer (lowest score, 3/5) flags as HARD that code and processed data are gated behind 'available upon reasonable request' with no repository, DOI, or seed disclosure — for optimization runs explicitly described as using 'randomly generated' starting values. Together these mean every figure in Section 3 (PMFs, densities, moments) rests on an implementation that is neither independently checkable nor benchmarked against a simulation.
