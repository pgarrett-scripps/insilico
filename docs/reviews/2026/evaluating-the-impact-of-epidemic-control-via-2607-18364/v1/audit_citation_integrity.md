# Citation Integrity Auditor

## Summary
The manuscript contains citations across four main categories: reference resolvability (extensive bibliography with complete journal details), claim–citation support (methodological and epidemiological claims attributed to specific works), data source attribution (mpox data from Our World in Data), and self-citation (multiple recent works by the first author). All detected citations are complete with journal names, volumes, and page numbers, enabling resolution. However, due to tool limitations, all claim–citation pairs are marked unverifiable rather than confirmed. One soft concern: non-germane self-citation (Papageorgiou 2026a on terrorism radicalization) appears in the scope discussion. No retracted or predatory sources detected. Data reproducibility is partially mitigated by authors' offer to provide processed data and code upon request, though public repository deposition would strengthen this. Future-dated access dates (17 July 2026 relative to manuscript arXiv date 20 July 2026) warrant clarification.
