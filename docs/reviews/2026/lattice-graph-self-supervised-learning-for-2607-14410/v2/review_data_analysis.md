# Statistics & Data-Analysis Reviewer

## Summary
The manuscript presents a technically sound framework (LATTICE) for multimodal spatial omics integration and reports a systematic evaluation across a modality ladder. The core quantitative claims are supported by appropriate metrics and comparisons. However, the central, load-bearing claim—that LATTICE successfully integrates five distinct modalities—is not fully established by the evidence presented. The evaluation relies heavily on agreement with a single-modality (RNA) reference, which is an inappropriate benchmark for assessing true *multimodal* integration. Furthermore, the analysis is conducted on private data using internal pipelines (ReCAST, SARSIM), making the reported effect sizes and performance gains impossible for a reader to verify or contextualize. The work is promising but requires a more rigorous, externally valid assessment of its multimodal capabilities.

## Strengths
- The evaluation employs a clear, incremental "modality ladder" (M1-M5) to dissect the contribution of each data source, which is a strong methodological choice.
- The authors correctly use multiple complementary metrics (ARI, NMI, spatial contiguity, silhouette) rather than relying on a single performance score.
- They introduce a novel composite metric (Multimodal Utility Score, MUS) to capture aspects of performance beyond simple clustering agreement.

## Weaknesses
- (Load-bearing) The primary claim of successful five-modality integration is benchmarked against a flawed standard. The key evidence offered is improvement in ARI/NMI against Space Ranger's RNA-only clusters. This is a circular test for multimodal integration: a method that perfectly fuses RNA with chromatin information may produce clusters that *diverge* from RNA-only clusters because they capture additional biology. The observed drop in ARI/NMI from M3 to M5 is interpreted as the model capturing "regulatory structure beyond transcriptomic similarity," but this interpretation is not validated. Without orthogonal biological validation (e.g., demonstrating that M5 clusters correspond to known histopathological or epigenetically defined tissue regions better than M2 clusters), the claim that lower RNA-agreement signifies *successful* integration of other modalities is unsupported. The alternative explanation—that the added noise or misalignment of non-RNA modalities is degrading the embedding's coherence—is equally plausible given the presented analysis.
- (Load-bearing) The quantitative results are unverifiable and lack external context. All analyses are performed on a private 11-sample cohort using internal preprocessing pipelines (ReCAST, SARSIM). The reported performance numbers (e.g., ARI improvements of +0.157) cannot be benchmarked against public state-of-the-art methods on standard datasets. It is impossible to judge whether the observed gains are substantial for the field or specific to this particular, unseen data. The claim that LATTICE is a "practical and empirically grounded framework" is weakened by the absence of any validation on public, reproducible data.
- The "multimodal utility score" (MUS) is not fully defined in the main text. The normalization procedure ("min–max normalized across all methods...") is critical to interpreting its value but is only described in the appendix. A score that is relative to a specific cohort and set of compared methods has limited general interpretability.
- The statistical support for claims like "stable optimization behavior" and "reproducible embeddings" is qualitative (e.g., "runs complete without failures"). A quantitative analysis of embedding stability across random seeds (e.g., average pairwise correlation of cluster assignments) would be more convincing.
- For the ablation study (Table 3), the n for each condition is implied to be the 11-sample cohort, but this is not explicitly stated. The standard deviations reported suggest variability, but without knowing if the same train/validation splits were used across ablations, it's unclear if the comparisons are fully controlled.
- The analysis of patient-level treatment effects (Fig 3, Section 4.3) correctly avoids claiming a universal signature but offers no statistical assessment of the within-patient pre/post shifts. A simple permutation test could quantify whether the observed joint PCA separation is greater than expected by chance.

## Questions
- To validate the central claim that M4/M5 embeddings better integrate multimodal biology, could you perform an analysis where you *predict* a modality from the others? For example, using the M5 embedding to predict spatial ATAC signal (held out) and comparing the prediction accuracy to that achieved using the M2 (RNA-only) embedding? Superior cross-modality prediction would be direct evidence of successful integration.
- You state the final intersected gene set is sample-specific (G ∈ [129, 322]). Does the variable input dimensionality (D = 5G) pose a challenge for model training or comparison across samples? Were any steps taken to mitigate the effects of this variability on the learned embeddings (e.g., feature weighting, adaptive architectures)?
- For the MUS metric: in the normalization step, what is the denominator pool "all methods and LATTICE modality-ladder rows"? Does this include the external baselines from Table 2? Clarifying this in the main text is essential for interpreting the reported MUS values (0.803 for M5).
- In the cross-modal alignment loss (Eq. 8), you treat features from different spots as negatives. For spatially smooth data, couldn't this penalize the model for correctly aligning modalities in adjacent, biologically similar spots? Have you experimented with alternative negative sampling strategies (e.g., spatially distant spots)?
