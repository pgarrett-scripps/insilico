# Methods Completeness & Reagent Traceability Auditor

## Summary
This bioprocess development manuscript describes cell line engineering, upstream fermentation, downstream purification, and product characterization for an HIV-1 vaccine candidate (N332-GT5 gp140). Detected categories include cell lines, antibodies/immunodetection, chemicals/reagents, oligos/plasmids/constructs, mass spectrometry, microscopy, and protocol provenance. Most core reagents (cell lines, antibodies, chromatography resins, media) are identified with vendor and catalog numbers. However, several load-bearing methods are delegated to citations without full protocol detail, and some key analytical parameters (software versions, statistical tests, sample replicates for key assays) lack explicit statement. Glycan analysis methods are described with sufficient detail for the LC-MS work, but the DeGlyPHER method relies on a 2023 reference. Viral clearance studies lack explicit n and statistical reporting. No data-availability statement or code-availability statement is provided.

## HARD gaps — reproduction blockers
- **[Cell lines] Mycoplasma testing** — No mycoplasma testing is mentioned for the HD BIOP3 parental line, the stable pool, or clone C235 at any stage of development or banking.
- **[Oligos/plasmids/constructs] Plasmid source or Addgene number** — No Addgene accession number or public repository identifier is provided for the expression constructs. The constructs are stated to be synthesized by ATUM but no accession or availability statement is given.
- **[Mass spectrometry] Mass spectrometry data repository accession (PRIDE/MassIVE)** — No PRIDE, MassIVE, or other public mass spectrometry data repository accession is provided for the DeGlyPHER or LC-MS glycoproteomics data.
- **[Protocol provenance] Statistical tests and error bar definitions** — Figures 7, 9, 10, 13, 14, 15, 16, and 17 display data with error bars or standard error of mean (SEM), but the manuscript does not explicitly state which statistical test was used for comparisons, whether error bars represent SD, SEM, or CI, or whether statistical significance testing was performed. Section 3.6.1 states 'Data are shown as the mean of abundance measurement of peptides mapping to individual PNGS with the standard error of mean' for Figure 17, but this is the only explicit statement.
- **[Protocol provenance] Sample size (n) and replication for key assays** — The manuscript does not consistently state n (number of replicates, biological or technical) for key assays. For example: Ambr250 optimization used 12 bioreactors (Section 2.4.2, Table 1) but it is unclear if these are biological or technical replicates. Feasibility runs (Section 2.5.1) mention multiple cycles but do not state n explicitly. Viral clearance study (Section 2.6, Table 12) shows mean ± SD but does not state how many independent experiments (n) were performed. Negative-stain EM (Section 2.7.2) analyzed 6,086 particles from one demonstration run but does not state if multiple grid preparations or multiple runs were analyzed.
- **[Protocol provenance] Software versions for analytical instruments** — CFX Manager software (Section 2.2.3) is named without version. Byos (Protein Metrics) for LC-MS analysis (Section 2.7.1) is named without version. IP2 (Integrated Proteomics Pipeline, Bruker) for DeGlyPHER analysis (Section 2.7.1) is named without version. ProLuCID, DTASelect2, and Census2 are named without versions in Section 2.7.1.
- **[Protocol provenance] Preclinical rhesus macaque study: IACUC approval and animal details** — The Introduction (Section 1) references preclinical studies in rhesus macaques (Steichen et al., 2024) demonstrating N332-GT5/SMNP efficacy, including priming of BG18-class precursor B cells in 'all eight animals tested.' However, no IACUC protocol number, approval statement, or animal housing/care details are provided in this manuscript. The study is delegated to Steichen et al., 2024 (reference 23).
- **[Protocol provenance] Transgene copy number determination method** — Section 2.3.8 mentions 'transgene copy numbers' as a stability indicator but does not describe the method used to determine copy number (e.g., qPCR, Southern blot, digital PCR, or other technique).
- **[Protocol provenance] Viral clearance study: virus spiking and quantification method** — Section 2.6 states: 'Each unit operation was performed separately, with known quantities of virus spiked into representative load materials. Viral clearance was calculated by measuring the log (base 10) reduction of virus (LRV) for each unit operation.' However, the method for quantifying virus (e.g., TCID50, plaque assay, qPCR, particle counting) is not specified. The 'known quantities' are not stated with units or concentrations.
- **[Protocol provenance] Viral clearance study: XMuLV and MMV source and characterization** — Section 2.6 and Table 12 use 'Xenotropic Murine Leukemia Virus (XMuLV), an enveloped retrovirus, and Minute Virus of Mice (MMV), a non-enveloped adventitious virus' as model viruses. However, no source (vendor, strain, lot number, titer, or characterization) is provided for either virus.
- **[Protocol provenance] Viral clearance study: sample size and replication** — Table 12 shows mean ± SD for viral log reduction (e.g., '2.95 ± 0.57' for 2G12 affinity chromatography with XMuLV), but does not state n (number of independent experiments or replicates) used to calculate these values.

Spectra searched using ProLuCID against N332-GT5 sequence within CHO proteome background. Static modification: C+57.02146 Da. Variable modifications: N+2.988261 Da (complex glycans), N+203.079373 Da (high-mannose/hybrid), M+15.994915 Da, N-terminal Q–17.026549 Da. Filtered to 1% FDR using DTASelect2. Quantified with Census2 label-free analysis. GlycoMSQuant used for final results.

Glycoforms identified by searching for known peptides and glycopeptides with known molecular weights from glycoform library of oligomannose and complex-type glycans.
