# Reproducibility Reviewer

## Summary
This manuscript presents a large-scale bioinformatics analysis of 821 TB drug-resistance mutations across 31,073 isolates from 149 studies. While the data collection effort is substantial and the computational pipeline is described, critical reproducibility barriers prevent independent replication: the mutation dataset itself is not deposited in any public repository with a DOI or accession number; no custom code is made available; key computational parameters are missing or scattered across methods; and the chain from raw literature data to final mutation atlas is not fully transparent. The authors promise supplementary tables but do not specify whether these will be publicly archived or remain author-controlled. Without access to the curated mutation dataset and the analysis scripts, a replicator cannot verify the frequency calculations, conservation predictions, or mutation rankings that underpin all major claims.

## Strengths
- The data collection protocol is explicitly described with inclusion/exclusion criteria (Fig. 4, Methods), allowing traceability of the 149 studies selected from 1,486 initial records.
- Multiple bioinformatics tools are named for each analytical step (ConSurf, SIFT, PROVEAN, PolyPhen-2, I-MUTANT 3.0, mCSM, AutoDock), with tool versions provided for some (MODELLER v9.23, GROMACS 4, AutoDock 4.2).
- The mutation atlas (Supplementary Table S3) is referenced as a key output and is stated to contain amino acid substitutions, phenotypic resistance counts, and mutation frequencies—the raw material for reproducibility.
- The paper specifies energy minimization parameters (GROMACS96 43A1 force field) and docking parameters (200 population size, 2 million evaluations, 100×100×100 grid, 0.375 Å spacing) for AutoDock.

## Weaknesses
- **HARD: No public data repository.** The curated mutation dataset (821 non-synonymous mutations from 31,073 isolates) is not deposited in any public database with a DOI or accession number. The manuscript states 'Supplementary Table S3' contains this atlas but does not specify whether it will be publicly archived or remains under author control. This is a load-bearing artifact: all frequency calculations, conservation analyses, and mutation rankings depend on it.
- **HARD: No custom code availability.** The manuscript describes a 'comprehensive bioinformatics framework' (Fig. 3) and a 'five-step computational pipeline' but provides no repository link, GitHub URL, or archived code (e.g., Zenodo DOI). Scripts for data aggregation, frequency calculation, site categorization (site-1, site-2, site-3), and mutation ranking are not made available.
- **HARD: Missing critical parameters for mutation ranking.** Section 3.6.2.5 introduces the ranking of mutations into 'lethal, moderate, mild, and neutral' categories based on 'concordance analysis' of functional, stability, and binding predictions. The exact thresholds, decision rules, and weighting scheme for combining outputs from SIFT, PROVEAN, PolyPhen-2, I-MUTANT 3.0, and mCSM are not specified. The phrase 'concordance analysis' is not defined. Without these rules, the 340 'lethal', 284 'moderate', 185 'mild', and 12 'neutral' classifications cannot be reproduced.
- **HARD: Incomplete specification of ligand-binding site identification.** The manuscript states 'COACH-D and 3D LigandSite web server was used for predicting ligand binding sites' and references Supplementary Table S6 for details. However, the manuscript does not specify the consensus threshold, e-value cutoff, or decision rule for resolving disagreement between the five methods within COACH-D (ConCavity, TM-SITE, FINDSITE, COFACTOR, S-SITE). Without this, the categorization of mutations into site-1 (binding), site-2 (supporting), and site-3 (other) cannot be verified.
- **HARD: Mutation frequency calculation not fully transparent.** The formula for single mutation frequency is provided in Methods, but the denominator is ambiguous: 'Total number of resistant isolates in a drug target having that mutation.' Does this mean isolates sequenced for that specific target, or all resistant isolates in the dataset? For katG, the text states 'S315T was observed at katG315 position harbouring 3690 mutations in 5667 phenotypically INH resistant Mtb isolates' (Section 3.6(i)), but it is unclear whether 5667 is the denominator for all katG mutations or only those with sequencing data for that position. This ambiguity affects reproducibility of the frequency percentages reported in Table 1 and Supplementary Table S3.
- **HARD: Structural modeling parameters incomplete.** The manuscript states 'Ten structural models were generated for each variant' using MODELLER v9.23, but does not specify the loop modeling algorithm, optimization iterations, or the exact criteria for selecting the best model beyond 'lowest DOPE score and highest GA341 score.' The energy minimization step mentions 'GROMACS96 43A1 force field' but does not specify convergence criteria, number of steps, or temperature. Without these, the 603 mutant protein structures cannot be regenerated.
- **HARD: Docking procedure not fully reproducible.** AutoDock parameters are specified (200 population, 2 million evaluations, 100×100×100 grid, 0.375 Å), but the manuscript does not state: (i) how the grid center was chosen relative to the ligand-binding site; (ii) whether the same grid was used for all mutations of a given target; (iii) how the 'best conformer' was selected from output clusters (lowest energy? highest cluster size?); (iv) whether multiple docking runs were performed and averaged. The binding energy values in Table 1 (e.g., S315T = −4.99 kcal/mol) cannot be verified without these details.
- **SOFT: Supplementary tables not deposited.** The manuscript references Supplementary Tables S1–S11 extensively (e.g., 'Supplementary Table S3 provides the information collected from the 149 research articles'; 'Supplementary Table S5 provides detailed information of the ligand-binding site'). However, it is not stated whether these tables are included in the preprint or will be made available upon publication. If they are 'upon publication' or 'on request,' this violates reproducibility standards for a general journal.
- **SOFT: No random seed or reproducibility statement.** The manuscript does not state whether MODELLER, GROMACS, or AutoDock runs were seeded for reproducibility, or whether results were averaged over multiple runs. This is a SOFT issue for computational tools that may have stochastic components, but it should be addressed.
- **SOFT: Concordance analysis methodology vague.** The phrase 'concordance analysis was done for integrating results from the previous mutation analysis' (Section 3.6.2.5) is not defined. Does this mean all three tools (SIFT, PROVEAN, PolyPhen-2) must agree? A majority vote? A weighted score? The text states '507 were predicted as deleterious (D) and 79 as neutral (N) to biological function by all three programs,' but it is unclear how the remaining 235 mutations (821 − 507 − 79) were classified or whether they were excluded from ranking.
- **SOFT: Missing intermediate outputs.** The manuscript does not state whether intermediate files (e.g., MODELLER output models, GROMACS energy minimization logs, AutoDock docking poses, ConSurf conservation scores) are retained or available. Retaining these would aid verification of the pipeline.

## Questions
- Where will the curated mutation dataset (Supplementary Table S3) be deposited? Will it have a DOI or accession number, or will it be available only on request from the authors?
- Will custom analysis code (for data aggregation, frequency calculation, site categorization, and mutation ranking) be made available on GitHub, Zenodo, or another public repository? If so, at what URL and with what commit/tag?
- What are the exact thresholds and weighting rules used to classify mutations into 'lethal, moderate, mild, and neutral' categories? How are the outputs of SIFT, PROVEAN, PolyPhen-2, I-MUTANT 3.0, and mCSM combined?
- For ligand-binding site prediction, what consensus rule was applied across the five methods in COACH-D? If methods disagreed, how was the final site-1 boundary determined?
- In the mutation frequency calculation, what is the exact denominator for each drug target? For example, for katG, is the denominator 5667 (total INH-resistant isolates) or the number of isolates with sequencing data specifically for katG?
- What are the convergence criteria and number of steps for GROMACS energy minimization? Were any structures rejected for failing to converge?
- For AutoDock docking, how was the grid center chosen? Was the same grid used for all mutations of a given target? How was the 'best conformer' selected from output clusters?
- Were MODELLER, GROMACS, or AutoDock runs seeded for reproducibility? If stochastic, were multiple runs performed and results averaged?
- Will all supplementary tables (S1–S11) be publicly deposited, or will they be available only upon request?
- Can the authors provide a step-by-step protocol (e.g., a protocols.io DOI) that consolidates all procedural details for independent replication?
