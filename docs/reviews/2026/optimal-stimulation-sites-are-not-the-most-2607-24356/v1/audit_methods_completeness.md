# Methods Completeness & Reagent Traceability Auditor

## Summary
This computational study fits reservoir-computing models to resting-state fMRI data from Alzheimer's disease patients and controls, then uses in-silico perturbation to test stimulation targets. Computational/ML and human-subjects categories apply. The manuscript provides dataset source (ADNI), cohort sizes, cross-validation schemes, and code availability (GitHub). However, several HARD items are missing or unverifiable: (1) random seed specification for the fixed reservoir is absent; (2) the exact ADNI data-release version/date is not stated; (3) IRB approval details are minimal (only a generic statement that ADNI was approved); (4) key hyperparameters and training details are scattered or incomplete (e.g., the feedback gain f=0.1 is stated but not justified, the choice of τ is called 'effectively instantaneous' without a value, spectral radius 0.95 is given but sensitivity is not explored); (5) the tangent-space SVM benchmark uses a 'train-only tangent reference' but the exact construction and reproducibility of this reference is not fully specified. Several SOFT items are also missing: no ablation studies on key design choices (e.g., reservoir size N=2000, input weight scale σ_in=0.01), no explicit environment file or requirements.txt, and no power calculation justifying the cohort size. The leakage-free cross-validation (leave-one-AD-patient-out) is described in Methods but the code availability statement does not explicitly confirm that this analysis is included in the repository.

**HARD gaps (blocking): 3** · SOFT gaps: 6 · unverifiable: 3

## HARD gaps — reproduction blockers
- **[Computational/ML/modeling] Random seed specification for fixed reservoir initialization** — The reservoir is described as 'fixed random recurrent network' with 'internal weights J (Gaussian, rescaled to spectral radius 0.95)' and 'fixed random input weights J_in (σ_in = 0.01)' (Methods, Eq. 1). No random seed or seed-averaging statement is provided. The same reservoir is reused for every session, but how the initial random J and J_in are generated and whether this is reproducible is not stated.
- **[Computational/ML/modeling] Software/library versions (NumPy, scikit-learn, nilearn, Matplotlib, Python version)** — Statement: 'Analyses were implemented in Python (NumPy, scikit-learn, nilearn, Matplotlib)' (Methods, Statistics and software). No version numbers are provided for any library or Python itself. This is insufficient for reproducibility.
- **[Human subjects/clinical] Participant demographics (age, sex, education, MMSE/cognitive scores)** — No demographic table is provided. The manuscript states cohort sizes (40 CC, 40 AD for main analyses; 145 CC, 41 AD in the full pool) but does not report age, sex, education, disease duration, MMSE, or other clinical characteristics. This is a significant omission.

## Unverifiable (raise as questions)
- **[Computational/ML/modeling] ADNI dataset version and release date** — Data source is stated as 'Alzheimer's Disease Neuroimaging Initiative (ADNI) database (adni.loni.usc.edu)' with download date not specified. ADNI releases multiple versions and updates; the exact data freeze or release version used is not stated, making it difficult for a reader to obtain the identical cohort.
- **[Computational/ML/modeling] Tangent-space SVM benchmark: exact construction of train-only tangent reference** — Methods state: 'Ledoit–Wolf covariance projected to the tangent space at a train-only reference mean' (Methods, Data and preprocessing). The exact procedure for computing the 'train-only reference mean' in nested CV is not fully specified. It is stated that 'no test information enters the feature construction' but the precise algorithm (e.g., how the reference is updated in the inner vs outer loop) is not detailed enough to reproduce exactly.
- **[Human subjects/clinical] Inclusion/exclusion criteria for CC and AD groups** — The manuscript states 'cognitively unimpaired controls (CC) and patients with Alzheimer's disease (AD)' but does not specify the diagnostic criteria (e.g., NINCDS-ADRDA, DSM-5), cognitive cutoffs (MMSE, MoCA), or exclusion criteria (e.g., other neurological disease, medication). These are presumably defined in the ADNI protocol, but the manuscript does not cite or summarize them, making it unverifiable from the paper alone.

## SOFT gaps — recommended
- **[Computational/ML/modeling] Justification or sensitivity analysis for key hyperparameters (reservoir size N, spectral radius, input scale)** — Reservoir size N=2000, spectral radius 0.95, and input weight scale σ_in=0.01 are stated as fixed choices with no ablation, sensitivity analysis, or justification provided. The paper does not explore how results depend on these choices.
- **[Computational/ML/modeling] Hardware specification and compute budget** — No mention of hardware (CPU/GPU), memory requirements, or compute time. The paper does not state whether analyses ran on a laptop, cluster, or GPU.
- **[Computational/ML/modeling] Environment file (requirements.txt, environment.yml, or equivalent)** — No mention of an environment file, dependency list, or Docker container. Readers cannot easily install the exact versions of dependencies used.
- **[Computational/ML/modeling] Ablation studies on key design choices** — No ablations on reservoir architecture (size, spectral radius, input scale), PCA dimension (beyond the reconstruction error in Fig. S2), or classifier choice (LDA vs RF are compared but not against other classifiers). The paper does not explore sensitivity to these choices.
- **[Human subjects/clinical] Sample size justification or power calculation** — No power calculation or sample-size justification is provided. The choice of 40 CC and 40 AD subjects is not explained. Fig. S1 shows that accuracy scales with cohort size and projects higher accuracy at N=100–200, but this is post-hoc, not a prospective justification.
- **[Human subjects/clinical] Reporting guideline adherence (e.g., STROBE, CONSORT)** — No mention of adherence to reporting guidelines such as STROBE (for observational studies) or CONSORT (for trials). The paper is observational and cross-sectional, so STROBE would be appropriate, but it is not cited or followed explicitly.

## Documented (for the record)
- **[Computational/ML/modeling] Exact train/val/test split specification and reproducibility** — Cross-validation scheme is clearly stated: 'repeated stratified 5-fold cross-validation (80/20 train/test, 10 repeats)' for main analyses (Methods, Classification section). Nested 5×5 patient-level CV is used for the tangent-space benchmark with 'fixed, saved fold indices for reproducibility' (Fig. 3 caption). Leave-one-AD-patient-out CV is described for leakage-free validation (Methods, Leakage-free target selection). Fold indices are stated to be saved, supporting reproducibility.
- **[Computational/ML/modeling] Hyperparameters: feedback gain, membrane time constant, spectral radius, input weight scale** — Feedback gain f=0.1 (Methods, Closed-loop reconstruction). Membrane time constant τ described as 'short' and 'effectively instantaneous update' but no numerical value given (Eq. 1). Spectral radius 0.95 (Methods, Reservoir model). Input weight scale σ_in = 0.01 (Methods, Reservoir model). Ridge regularisation noise σ swept over [0.003, 0.5] with reference σ=0.025 (Methods, Read-out fitting; Fig. 3). However, τ is not numerically specified, only qualitatively described.
- **[Computational/ML/modeling] Training procedure: optimizer, learning schedule, early stopping, convergence criteria** — Read-out W is fit by 'ridge-like regularised least squares with additive Gaussian noise' (Eq. 2, Methods). This is a closed-form solution, not an iterative optimization, so optimizer and schedule do not apply. Convergence is implicit in the pseudoinverse. No early stopping is mentioned because the fit is non-iterative.
- **[Computational/ML/modeling] Code availability and repository details** — Statement: 'All analysis and figure-generation code is openly available at github.com/cristianocapone/AD-reservoir-FC-stimulation' (Methods, Data and code availability). Repository URL is provided. However, the statement does not confirm that the code includes the leakage-free cross-validation analysis or that it is version-controlled with a specific commit hash or release tag.
- **[Computational/ML/modeling] PCA projection: justification for N_PC=50 and impact on downstream analyses** — N_PC=50 is stated (Methods, Population principal-component projection). Justification is given: 'removes idiosyncratic high-order variance while preserving the dominant spatiotemporal structure.' The impact is assessed in Fig. S2 (training/test reconstruction error vs K_PC and M), showing that test error plateaus for K_PC≥100, supporting the choice. However, the choice of 50 specifically (rather than, say, 75 or 100) is not explicitly justified.
- **[Computational/ML/modeling] Metric definitions: balanced accuracy, AUROC, distance (1-corr), net cure** — Balanced accuracy and AUROC are standard metrics, defined implicitly. Distance is defined as '1 − corr' (Pearson correlation) between stimulated and unstimulated FC (Fig. 5 caption). 'Net cure' is defined as 'the fraction of patients on the AD side at baseline that stimulation moves to the CC side' (Methods, Leakage-free target selection). All are sufficiently clear.
- **[Human subjects/clinical] IRB approval and informed consent** — Ethics section states: 'This work is a secondary analysis of de-identified, publicly available human imaging data obtained from ADNI. The ADNI study was approved by the institutional review boards of all participating sites, and all participants (or their authorised representatives) provided written informed consent at enrolment; no new data were acquired for the present study.' (Methods, Ethics). This is sufficient for a secondary analysis of public data.
- **[Human subjects/clinical] Conflict of interest and funding disclosure** — Funding is stated: 'This work has been partially supported by the National Plan for Complementary Investments to the NRRP, project "D34H—Digital Driven Diagnostics, prognostics and therapeutics for sustainable Health care" (project code: PNC0000001), Spoke 3, funded by the Italian Ministry of University and Research.' (Acknowledgments). No conflict of interest statement is provided, but none is apparent.
