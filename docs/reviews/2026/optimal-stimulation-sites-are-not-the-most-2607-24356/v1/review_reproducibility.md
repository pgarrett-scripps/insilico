# Reproducibility Reviewer

## Summary
The manuscript provides substantial procedural detail and makes code and data availability commitments that support reproducibility, but several load-bearing artifacts lack complete specification or are gated behind access restrictions. The reservoir model fitting, classification pipelines, and in-silico stimulation analyses are described with sufficient parameter detail to attempt replication, and code is promised at a public repository. However, the ADNI data access model (controlled-access, requiring registration and data-use agreement) creates a hard gate for independent replication, and some critical procedural details—particularly around the transductive vs. leave-one-out embedding construction and the exact order of operations in the closed-loop stimulation—require clarification. These are fixable issues that do not invalidate the work but do impose friction on replication.

## Strengths
- Code availability is explicitly promised at a public GitHub repository (github.com/cristianocapone/AD-reservoir-FC-stimulation), with no mention of embargo or author-discretion gating.
- Hyperparameters and model specifications are largely complete: reservoir size (N=2000), spectral radius (0.95), input weight scale (σ_in=0.01), membrane time constant (τ), read-out regularisation noise (σ=0.025 unless swept), PCA projection (N_PC=50), and classifier settings (LDA, RF with stated tree/leaf counts) are all provided.
- Preprocessing and data handling are documented: parcellation scheme (Schaefer-100 + HO-21), confound regression (24-HMP + WM + CSF), bandpass filter (0.01–0.10 Hz), and session counts per group (Table S1) are specified.
- Stimulation protocols are parameterised: interpolation strength α ranges, oscillation amplitudes A, frequency sweeps, and the resonant frequency f_eig=0.077 cycles/step are all stated.
- Cross-validation scheme is explicit: repeated stratified 5-fold (80/20), 10 repeats, with balanced class weights and leave-one-patient-out variants clearly distinguished.
- Physiological diagnostics (RMS_pert/RMS_base, mean |FC| at stimulated sites) are reported to validate amplitude claims, supporting reproducibility of the amplitude-response curves.

## Weaknesses
- ADNI data are controlled-access and require registration and data-use agreement acceptance; the manuscript states 'available to qualified researchers upon registration' (Methods, Data and code availability), which is a hard gate for independent replication. While this is a legitimate data-access model, it means a replicator cannot obtain the raw data without institutional approval and ADNI consent, creating friction that must be disclosed.
- The transductive embedding construction is ambiguous: the manuscript states 'the SVD embeddings were built transductively (across all patients) while the classifiers were trained and tested on disjoint folds' (Methods, Classification), but it is unclear whether the Gram-matrix SVD for FC-lag features is computed once on all patients and then projected per-fold, or recomputed per fold. This is critical for assessing leakage and reproducibility. The leave-one-patient-out (LOPO) variant is described separately (Methods, Leakage-free target selection), but the default transductive procedure's exact fold-wise operation is not explicit.
- The closed-loop reconstruction procedure has an ambiguous reset/initialization step: the manuscript states 'the reservoir was reset and run closed-loop: the real target drove the network for the first 5 steps, after which it free-ran' (Methods, Closed-loop reconstruction), but does not specify how the reservoir state x(t) is initialised (zero, random, or from teacher-forced warmup). This affects reproducibility of the lagged-FC validation (Fig. 2I).
- The read-out 'G-space' projection is incompletely specified: the manuscript projects W onto the row space of X using 'the top K_PC=200 right singular vectors of X' (Methods, Read-out G-space), but does not state whether X is computed per-session or pooled across sessions, and whether the SVD is recomputed per fold or shared. The justification (Fig. S2) shows training/test error but does not validate the choice against the classification results.
- The population-average LDA-resonant site selection (Fig. S3A, S9B) is described as 'the site whose resonant drive moves that patient's FC-lag discriminant most toward CC' (Methods, Leakage-free target selection), but the exact ranking criterion (argmax of score reduction, or argmax of per-site effect size?) is stated only in the LOPO section and not clearly applied to the transductive case. This affects reproducibility of Fig. 5A and Fig. S3.
- Software versions are not provided: the manuscript lists Python libraries (NumPy, scikit-learn, nilearn, Matplotlib) but does not specify versions, scikit-learn hyperparameter defaults (e.g., solver for LDA, tree depth limits for RF), or Python version. This is a SOFT issue but limits exact reproducibility of the classifiers.
- The exact order of operations for the oscillatory stimulation is not fully specified: the manuscript states 'a sinusoid A sin(2πft) is injected as additional input at the top-k sites during the teacher-forced pass, with W unchanged' (Methods, Oscillatory stimulation), but does not clarify whether the oscillation is added to the target-driven input u(t)=f·ŝ(t) or injected separately, and whether the reservoir state is reset between frequency/amplitude sweeps.
- The feedback gain f=0.1 is stated for teacher-forcing but not justified or swept; it is unclear whether this choice affects the relative amplitude comparisons (e.g., RMS_pert/RMS_base in Fig. S10) or the resonance frequency.
- The even/odd test–retest ceiling (Fig. 2I, grey line) is mentioned but not defined: it is unclear whether this is computed from the empirical data (splitting sessions into even/odd volumes) or from the model, and over which sessions/patients the median is taken.

## Questions
- Can you clarify the exact procedure for the transductive SVD embedding in the classification pipeline (Methods, Classification)? Specifically, is the Gram-matrix SVD computed once on all patients and then the resulting coordinates projected per fold, or is it recomputed within each training fold? This is critical for assessing whether test-set information leaks into the embedding.
- How is the reservoir state x(t) initialised at the start of the closed-loop reconstruction (Methods, Closed-loop reconstruction)? Is it zero, or does it inherit state from the teacher-forced warmup? This affects reproducibility of Fig. 2I.
- In the read-out G-space projection (Methods, Read-out G-space), is the SVD of X computed per-session or pooled across all sessions? Is it recomputed per cross-validation fold?
- For the population-average LDA-resonant site selection (Fig. S3A, S9B), what is the exact ranking criterion? Is it argmax of the mean FC-lag score reduction across training patients, or argmax of the mean per-site effect size? How is this applied in the transductive case (Fig. 5A)?
- Can you provide the versions of Python, NumPy, scikit-learn, and other key libraries used? This will help ensure exact reproducibility of the classifiers.
- In the oscillatory stimulation (Methods, Oscillatory stimulation), is the sinusoid A sin(2πft) added to the teacher-forced input u(t)=f·ŝ(t), or injected as a separate input channel? Is the reservoir state reset between frequency/amplitude sweeps?
- The feedback gain f=0.1 is used for teacher-forcing but not justified. Was this parameter swept, and does it affect the relative amplitude comparisons (RMS_pert/RMS_base) or the resonance frequency?
- How is the even/odd test–retest ceiling (Fig. 2I, grey line) computed? Is it from the empirical data (splitting into even/odd volumes) or from the model, and over which sessions/patients?
