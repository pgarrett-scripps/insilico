# Methods Completeness & Reagent Traceability Auditor

## Summary
This manuscript describes biophysical and cell biological studies of MreB polymerization dynamics using multiple imaging modalities (TIRF, HS-AFM), biochemical assays (fluorescence anisotropy, ATPase activity, liposome binding), and computational modeling. Detected categories include: Chemicals/drugs/dosing (nucleotides, lipids, CCCP), Oligos/plasmids/constructs (MreB variants, site-directed mutagenesis, B. subtilis strains), Model organisms/in vivo (B. subtilis strains and imaging), Microscopy/imaging (TIRF, HS-AFM, TEM, QCM-D, epifluorescence), and Computational/ML/modeling (Monte-Carlo stochastic model). The manuscript provides substantial methodological detail in the Materials and Methods section, including protein purification, lipid preparation, microscopy protocols, and strain construction. However, several items lack complete traceability: some fluorescent reagents lack vendor catalog numbers; the Monte-Carlo model lacks explicit random seed reporting; some referenced protocols are delegated to citations without full verification of their contents; and the data/code availability statement is conditional ('after publication'). Sample sizes are generally stated with replicates specified, and statistical tests are named with error bars defined.

## Unverifiable (raise as questions)
- **[Model organisms/in vivo] B. subtilis genotype and background strain** — Strain RCL0421 is described as 'expressing a translational gfp-mreB fusion previously shown to be functional' (line 529), but the full genotype and parental background are not provided in the main text. The manuscript states these details are in 'Supplementary Table S2' (line 521), which is not accessible from the manuscript alone.
- **[Computational/ML/modeling] Monte-Carlo stochastic model — algorithm description, parameters, and random seed** — A stochastic Monte-Carlo model is described (line 285, Fig. 4D). The model incorporates 'experimentally determined kinetic parameters for polymerization, depolymerization, ATP hydrolysis, Pi release and nucleotide exchange' (line 286). Standard parameter values are listed in Fig. 4D legend (line 451): k+,t = 45 µM−1s−1, k−,t = k−,dp = 0.135 s−1, k−,d = 60 s−1, k−,e = 4 s−1, khyd = kPir = 1.54 × 10−3 s−1, k+,n = 0.28 µM−1·s−1, k−,n = 0.0141 s−1. However, no random seed is reported, and the full algorithm is delegated to 'Supplementary Information, 'Modeling MreB dynamics'' (line 286). The supplementary text is not accessible from the manuscript alone.
- **[Computational/ML/modeling] Monte-Carlo model — code availability and reproducibility** — The data-availability statement (line 883) says 'Research data will be deposited on Zenodo after publication and are available from the corresponding authors upon request.' Code availability is not explicitly mentioned. The model is described as 'stochastic' but no code repository (GitHub, Zenodo, etc.) is cited, and no statement about code release is made.
- **[Computational/ML/modeling] Monte-Carlo model — training/simulation procedure and convergence criteria** — The model is used to simulate MreB filament dynamics under various conditions (Fig. 4, Fig. S8, S9, S10). However, the simulation procedure (e.g., number of runs, time steps, convergence criteria, initial conditions) is not described in the main text. The manuscript states 'The model accurately reproduces MreB polymerization kinetics in the presence of ATP (Fig. S8)' (line 288) but does not specify how accuracy was assessed or what tolerance was used.

However, no code repository or availability statement is provided for this custom script.
