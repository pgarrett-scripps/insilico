# Methods Completeness & Reagent Traceability Auditor

## Summary
The manuscript 'Intrafilament nucleotide exchange in a prokaryotic actin homolog' uses a wide range of methods: protein purification, lipid biochemistry, TEM, HS-AFM, TIRF microscopy, QCM-D, fluorescence anisotropy, ATPase assays, in vivo bacterial microscopy, and stochastic Monte-Carlo modeling. The audit checked cross-cutting reproducibility items (sample sizes, statistics, software versions, data/code availability) and conditional categories triggered by the work: model organisms (B. subtilis, E. coli), chemicals/drugs, oligos/plasmids, microscopy, computational modeling, and protocol provenance. Many required identifiers are missing or unverifiable: sample sizes often do not distinguish biological vs technical replicates; statistical tests are not reported per figure; key software versions (ImageJ, MATLAB, PRISM, SOAX, TSOAX) are omitted; custom Monte-Carlo code is not deposited; B. subtilis strain sources/RRIDs and full genotypes are not provided; numerous chemicals lack vendor/catalog numbers; primer sequences are only referenced to a supplementary table that was not provided for verification; several method delegations cite incorrect or implausible references (e.g., SOAX/TSOAX cited to unrelated papers). These gaps would prevent an independent lab from exactly reproducing the work.
