# Writing rules

- Never use an em dash or a semicolon in In Silico-authored prose.
- This rule applies to website copy, project documentation, interface labels, workflow messages, commit messages, and assistant responses.
- Published review artifacts under `docs/reviews/`, reviewer output, manuscript metadata, and source code syntax are exempt.
- Rewrite sentences with periods, commas, colons, or parentheses.
- Before finishing a change, check project-authored text for both forbidden punctuation marks.
